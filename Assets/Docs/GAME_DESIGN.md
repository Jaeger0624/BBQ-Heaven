# 项目策划案

## 简单介绍
类小丑牌 肉鸽 构筑 模拟经营
2D 游戏

## 关键词
- 肉鸽
- 构筑
- 强反馈、生动（目前的类小丑牌都太死板了，一定要学习戴夫的生动性，可交互性）

## 玩法
1. 游戏的得分机制是参考《小丑牌》/《幸运房东》的，即每小局结束后检查是否满足目标分数，若满足则继续。
2. 游戏的得分过程分成两步：1. 制作串串  2. 把串串卖给合适的顾客
3. 时间系统：本游戏使用离散的“时间点”来表示小局进程与资源分配，例如，今日经营时间为40分钟，这个40分钟也即40个时间点，制作串、补充食材牌库、使用卡牌等操作都需要消耗时间点（或者说推进时间）。
4. 制作串串：
  1. 本游戏的核心策略玩法，围绕棋盘玩法展开。
  2. 使用卡牌（可选），控制、影响棋盘上的食材。
  3. 选择一根合适的串签，不同串签的属性不同（串签属性：最大可串数量、基础时间消耗、时间消耗增长等）
  4. 鼠标移动至棋盘上，会显示出串签当前选中的范围，点击左键为确认，点击右键为旋转（有上下左右四个串的方向，都是串一行或者一列），如果一列上有6个食材，但是这个签只能串4个的话，串到第4个就算作这个串串制作完成。
  5. 食材是如何到棋盘上的呢？最主要的方式是通过“抽取食材卡”，在本游戏中，食材在小局内以食材卡的形式存在，玩家构筑时也是通过购买、升级食材卡。抽取食材卡时，会将该食材卡的食材随机放置在棋盘的一处。食材牌库不会自动补充，当抽空后，需要花费时间补充。
    1. 食材卡本身可以被升级（一张食材卡默认2个升级槽位），升级有如【双倍：放置两个该食材】【轻食：该食材时间消耗-1】
  6. 制作串串的耗时规则：制作一根串所需时间 = 串签基础时间消耗 + 串签额外时间消耗（一根串签反复用会提高时间消耗）+ 串上所有食材的时间消耗之和
    1. 例如：我选了一根木串（基础时间消耗为3，串过两次，额外时间消耗为4），然后串了4个食材，分别对应的时间消耗是1,2,1,1，则总时间消耗为12
  7. 串串制作完毕后
    1. 制作完的串会被放在待售区，等待出售给一个顾客。
    2. 在出售给顾客之前，所用的串签不会回收。出售后，可以再次使用（但额外时间消耗会增加）。
    3. 弃置之前手牌，重新抽取手牌。（类似《杀戮尖塔》结束回合后，在下次回合开始前会进行一次手牌刷新）
    4. 初始默认每次串完串后，抽取3张食材卡
  8. 串串的属性与食材的属性：美味度与珍稀度，两个值，参考小丑牌有“倍率”和“筹码”两个值。但目前在该游戏中美味度和珍稀度两个值的地位是同等。（小丑牌中前期筹码获取比倍率容易多了）
  9. 串串的属性计算/串串的制作过程
    1. 根据所选的串制方向，逐个将范围内的食材串上串签。食材放上串签时会把食材自身的属性添加到串的总属性中。
    2. 食材会有很多特殊时机触发的效果，如【上串前触发】是在食材被放上串签之前触发的效果。
5. 卖给顾客：
  1. 将制作完的串串出售给选中的顾客时，会先计算基础得分，即串的美味、珍稀度相乘（例如一个30/40的串，基础得分是1200），之后会判断顾客的各种要求等等，可能有一系列的乘区、加分等。
  2. 同时，与一众类小丑牌或得分类肉鸽构筑游戏不同的点在于，每个顾客不是订单结束后就消失了，他们是有血有肉的，可能会在未来再次光临，或带来礼物，或带来故事，或带来机遇（选项或事件）。
  3. 顾客分为特殊顾客（或npc）与随机顾客，前者是设定好的，后者会随机生成。每个顾客都有其个性与喜好，即顾客标签（CustomerTag）。顾客每次来都会对串有不同的要求，出售满足要求的串给他们，可以触发对应要求（Requirement）的奖励。
    1. 要求的奖励有3种：声望、金币、倍率（乘在这次结算的总分数上）
  4. 顾客交易结算完毕后，会增长声望（基础默认为2点）
  5. 顾客有耐心值/等待值（默认为25分钟），如果超过时间还未服务的话，顾客可能离开，并且默认扣除声望（默认一点），有些顾客根据Tag不同，可能还会有其他行为。
  6. 正常一个顾客服务完毕后，该顾客会进入“顾客志”，成为“老顾客”
  7. 顾客志：记录了服务过的所有顾客
    1. 系统每次让一个顾客来的时候（有规则计算），有确认的概率是老客（默认30%）
      1. 经营日间可以选择第二天的开张时间（午市或夜市），夜市人流量更大更热闹（老客概率20%，主要用来积累新客人），午市更能吸引老客（老客概率50%）
    2. 不管是新客还是老客，当天来过后都不会再来第二次。
    3. 随着服务次数增加，会提升该顾客的“熟客等级”，等级越高，会根据顾客不同的Tag等信息，有奖励或者其他行为（例如触发剧情等）
6. 玩家主要构筑元素
  1. 食材：相当于《小丑牌》中的牌，是得分、combo的最小单元
  2. 串签：单次制作烤串时，选用不同串签可能有不同效果（或者行为、表现不同）
  3. 吉祥物：类似于《小丑牌》中的小丑牌，也类似于《杀戮尖塔》中的遗物（但不是无上限的，有最大拥有数量，所以更像小丑牌）。拥有全局效果
  4. 卡牌：玩家可以使用卡牌（类似杀戮尖塔中的卡牌）来造成各种效果（最简单的：例如给食材加属性，移动食材），用于在每次制作串串前控制棋盘、施加buff、收益最大化。
7. 经营事件（遭遇Encounter）
8. 日间事件与月度主题
  1. 一整局游戏分为若干月，每月分为若干经营日
  2. 经营日间有丰富的供玩家选择的提升和构筑手段，也可能有随机事件（一定程度上会根据玩家的顾客志触发）
  3. 每个月度会有不同的主题，影响这个月下所有经营日的全局效果和事件等内容。（如“夏日祭”、“水上狂欢节”等）
9. 游戏有丰富有趣的局外系统（连锁店、商店继承、顾客剧情、纪念品收藏、厨师培养等）

## 世界观想法
游戏想制作成一个个的关卡，每个关卡下面有难度1~10（类似这样）
而每个关卡是不同的星球，主角团们有点像星际中的旅商，前往不同的星球，遭遇独属于这个星球的顾客、事件，发现并使用这个星球特殊的食材制作美味的串串。也会在这个过程中结识（解锁）这个星球专属的厨师（玩家角色）加入我们的旅程。
目前想的第一关（第一个星球）是猫猫星，角色都是猫猫拟人，很可爱很Q萌（我们团队的美术擅长）。食材方面的话也可以用人类社会常见的一些食材就行。
第二关想的是一个偏魔幻世界观的星球，其中的随机事件有很多超自然元素，食材也更是各式各样（有点像迷宫饭），感觉会很有意思！
第三关目前想的是是一个精灵世界观，有点像宝可梦，居民和小精灵宠物共存的世界。在这个关卡下引入一个精灵系统（开局或者局内选择），定位上有点像吉祥物，但是可以在满足一些条件的情况下进化和升级，强化技能效果（而且支持分支选项，参与多种构筑）
第四关想的是一个科幻世界观，可能是机械星球，无机星球，可能的新机制是：串的属性（两个乘区）不是越高越好，而是顾客会有一个标准值，串的属性不多不少，越精准靠近这个值，最后的得分会越高（给个大满意度乘区）（但这样的话可能会打破之前几个星球的数值系统，所以只是大致一个想法，估计不会采用）
...
所以总结来说，不同关卡不同星球的设计，最终目的都是鼓励玩家持续探索和解锁新玩法，通过在新关卡中引入截然不同的机制或新玩法给玩家新鲜感和惊喜。
