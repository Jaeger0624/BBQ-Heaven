- BBQ系统 - 构造烧烤，计算烧烤属性
- Board系统 - 棋盘系统，控制棋盘上实体的交互和棋盘地块的效果
  - BoardEntity - 负责
- Food系统 - 主要负责食材仓储（卡牌构筑）和单局中的食材实例补充
- PC系统 - 玩家角色，主动、被动
- Mascot系统 - 吉祥物系统，全局效果
- GA系统 - GameAction，负责管理全局效果的实施，能够影响其他各系统
- Board系统 - 提供基本的棋盘控制，后续也会兼入地块系统
- Encounter系统 - 负责管理经营事件的系统
- Economy系统 - 负责存储几类游戏货币
- Shop系统 - 负责刷新商店内容
- Time系统 - 负责发布时间推动事件
- Recipe系统 - 管理配方的提醒、执行与获取
- Customer系统 - 顾客的来去、Tag、要求刷新等
- Deal系统 - 交易结算，单次得分
- Score系统 - 用于总结、记录单局得分等
- Stick系统 - 烤串的补充和使用
- Process系统 - 一轮完整游戏的管理（流程管理，日、月、局结算）
- Card系统 - 卡牌系统
- Dialogue&Guide - 对话与教程系统（两个是独立的，文件夹放在一起）
- Selector系统 - 用来统一处理高亮、选中逻辑，同时也负责创建选项（如从三张牌中选1个的界面）
- Display - 展示与视图相关的内容，例如该项目中，同一种东西在不同地方的展现是不一样的，例如食材卡，在图鉴、构筑展示区、商店，这些地方，具体怎么显示、交互是什么逻辑（商店要额外显示出价格，点击是购买），有Display相关的逻辑负责。
- Proxy系统 - 无头模式代理系统，用来在脱离View的情况下快速跑对局（正在开发中）
- RandomPool 系统 - 随机池系统，根据当前玩家局内情况动态分配随机结果（还未实现）
- Seed 系统 - Rng系统，种子，逻辑随机的唯一入口
