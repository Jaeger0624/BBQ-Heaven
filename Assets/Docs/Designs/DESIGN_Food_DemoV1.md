## 设计概述

### 用户故事
> 作为一名玩家，我希望每种食材都有独特的个性和玩法，让我在构筑时能够形成有趣的策略组合，而不是简单的数值堆叠。

### 核心设计原则
1. **类型差异化**：四种食材类型各有明确的玩法定位
2. **自洽性**：每种食材的效果与其现实特性相符
3. **可组合性**：食材之间可以形成有趣的combo
4. **复用优先**：优先使用已实现的GA，减少开发成本

## 一、海鲜类食材（Seafood）

### 类型定位
> **灵活多动、交互丰富，是碰撞与移动的触发者**

海鲜类食材强调棋盘上的动态交互，通过位移、碰撞来创造价值。

---

### 🦐 跳跳虾 (Jumping Shrimp)

| 属性 | 数值 |
|------|------|
| 美味值 | 4 |
| 珍稀值 | 4 |
| 时间消耗 | 1 |
| 稀有度 | 普通 |

**用户故事**
> "这只虾太活泼了！完成串串后还会跳来跳去，每次跳跃都会变得更强！"

**效果描述**
- **【烤串构建后】**：向随机方向移动1格，并使自身获得 +2 美味值和 +2 珍稀值

**设计意图**
- 海鲜类的入门食材，让玩家理解"移动+成长"机制
- 简单直接的收益，降低理解门槛
- 移动可能为下一串创造更好的布局

**GA配置参考**（已有实现）
```json
{
  "type": 2,  // 烤串构建后
  "action": {
    "ID": "1",
    "conditions": [],
    "actions": [
      {
        "$type": "GA_方向位移",
        "info": { "strategy": 3, "value": { "$type": "DV_值", "number": 1 }, "types": [1] },
        "dir": 6,  // 随机方向
        "value": { "$type": "DV_值", "number": 1 }
      }
    ]
  }
}
```
*参考：`fooddatatable.json` - shrimp*

## 五、食材组合推荐

### 组合1：海鲜碰撞流
**核心食材**：跳跳虾 + 滑溜泥鳅 + 玉米 + QQ糖
**玩法**：利用海鲜的移动和碰撞触发玉米和QQ糖的成长，形成连锁效果。

### 组合2：水果增益流
**核心食材**：柠檬 + 葡萄 + 西瓜 + 水蜜桃
**玩法**：通过水果之间的相互增益，大幅提升串的属性值。

### 组合3：蔬菜投资流
**核心食材**：胡萝卜 + 豆芽 + 土豆
**玩法**：利用蔬菜的条件成长和增殖机制，在合适的时机获得高收益。

### 组合4：万能杂交流
**核心食材**：黑巧克力 + 曲奇 + 樱桃炸弹 + 任意食材
**玩法**：利用零食的灵活性，配合各种类型的食材获得均衡收益。
