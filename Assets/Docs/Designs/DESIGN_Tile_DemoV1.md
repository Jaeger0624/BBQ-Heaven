## 设计概述

### 用户故事
> 作为一名玩家，我希望棋盘上的地块能够提供丰富的策略选择，让我可以通过改变地块来创造有利的局面，形成有趣的combo。

### 核心设计原则
1. **机制深度**：地块效果与食材、串签等系统形成交互
2. **构筑价值**：地块可以成为特定构筑的核心组件
3. **combo潜力**：地块之间、地块与食材之间可以形成连锁效果
4. **视觉反馈**：地块效果应当直观易懂

### 地块触发时机

| 触发时机 | 枚举值 | 说明 |
|----------|--------|------|
| `实体被放置` | 0 | 食材被放置到该地块时触发 |
| `实体移动进入` | 1 | 食材从其他地块移动到该地块时触发 |
| `实体移动离开` | 2 | 食材从该地块移动到其他地块时触发 |

## 一、移动类地块

> **设计理念**：改变食材的位置，创造动态的棋盘局面

---

### 🧊 冰面 (Ice Floor)

| 属性 | 值 |
|------|-----|
| ID | `tile_ice` |
| 名称 | 冰面 |
| 稀有度 | 普通 |

**用户故事**
> "食材滑过冰面时会继续滑行，就像溜冰一样！配合海鲜的移动能力太爽了！"

**效果描述**
- **【实体移动进入】**：使食材沿原移动方向继续滑行1格（如果目标格为空）

**设计意图**
- 最基础的移动类地块
- 与海鲜类食材（跳跳虾、泥鳅等）形成combo
- 可以用来"传送"食材到更远的位置
- 简单直观的效果，降低理解门槛

**combo示例**
- 冰面 + 跳跳虾：放置后跳跃，再滑行，距离更远
- 冰面 + 泥鳅：选中后滑行，经过冰面再滑行，超长距离
- 连续冰面：形成"冰道"，食材可以滑行很远

**GA配置**
```json
{
  "type": 1,  // 实体移动进入
  "action": {
    "ID": "1",
    "conditions": [],
    "actions": [
      {
        "$type": "GA_方向位移",
        "info": { "strategy": 3, "value": { "$type": "DV_值", "number": 1 }, "types": [1] },
        "dir": { "$type": "DV_移动方向" },
        "value": { "$type": "DV_值", "number": 1 }
      }
    ]
  }
}
```

### 🌀 传送门 (Portal)

| 属性 | 值 |
|------|-----|
| ID | `tile_portal` |
| 名称 | 传送门 |
| 稀有度 | 稀有 |

**用户故事**
> "传送门成对出现，食材进入一个就会从另一个出来！太神奇了！"

**效果描述**
- **【实体移动进入】**：如果有配对的传送门，将食材传送到配对传送门的位置

**设计意图**
- 高级移动类地块
- 需要两个传送门配合使用
- 可以实现"瞬间移动"的效果
- 策略性极强，需要玩家规划传送门位置

**combo示例**
- 传送门 + 碰撞流：将食材传送到玉米旁边，立即触发碰撞
- 双传送门：形成传送网络，灵活调整食材位置

**特殊机制**
- 传送门需要成对配置（portal_a 和 portal_b）
- 传送后食材的移动方向不变

## 五、地块组合推荐

### 组合1：海鲜滑行流
**核心地块**：冰面 + 风洞 + 瞄准格
**玩法**：利用冰面和风洞让海鲜食材滑行更远，经过瞄准格获得精准状态，碰撞时造成更高伤害。

### 组合2：增益叠加流
**核心地块**：星光舞台 + 棱镜地板 + 充能格
**玩法**：将高价值食材移动到增益地块上，叠加多层增益，打造"超级食材"。

### 组合3：碰撞触发流
**核心地块**：漩涡格 + 磁力地板 + 瞄准格
**玩法**：利用漩涡和磁力创造大量碰撞机会，配合玉米、QQ糖等碰撞触发食材。

### 组合4：精准控制流
**核心地块**：传送门 + 墙壁格 + 转换器
**玩法**：精确控制食材位置，根据顾客需求调整属性，打造完美串串。

## 七、新增需求清单

### 7.1 新增DV

| DV名称 | 用途 |
|--------|------|
| `DV_移动方向` | 获取食材最近一次移动的方向 |

### 7.2 新增GA

| GA名称 | 用途 |
|--------|------|
| `GA_传送` | 将食材传送到指定位置 |
| `GA_效果复制` | 再次触发食材的指定时机效果 |
| `GA_属性转化` | 将一种属性转化为另一种 |
| `GA_添加状态` | 为食材添加状态（定身、充能、精准等） |

### 7.3 新增状态

| 状态名称 | 效果 |
|----------|------|
| `定身` | 无法被移动 |
| `充能` | 下次GA效果数值+50% |
| `精准` | 下次碰撞额外+3美味值 |

### 7.4 扩展TileEffectType

建议添加更多触发时机：
- `实体被选中`：食材被玩家选中时触发
- `回合开始`：每回合开始时触发
- `串取检测`：串签经过时触发

本设计文档包含17种地块，覆盖移动、增益、转化、特殊四大类型。

**架构师请注意**：
