# 猫猫星新手教程设计文档

## 概述

本文档描述了猫猫星新手教程的设计和配置方法。教程由向导角色"莫奇"（一只狡猾但善良可爱的奸商猫）引导玩家完成。

## 角色设定

| 属性 | 描述 |
|------|------|
| **名字** | 莫奇 (Mochi) |
| **身份** | 猫猫星店铺出租者 / 房东 |
| **性格** | 狡猾但善良可爱、精明、嘴硬心软 |
| **动机** | 玩家经营得越好，她收的租金越多 |
| **外观** | 橘猫，金丝边眼镜，算盘项链 |

## 使用方法

### 1. 生成配置文件

在 Unity 编辑器中执行以下操作：

```
菜单栏 > Tools > 教程 > 生成猫猫星教程配置
```

这将自动在 `Assets/Resources/SO/Tutorial/` 目录下生成：
- 1 个 `GuideFlow_CatPlanet.asset` 流程配置
- 20 个 `GuideStep_XX_XX_xxx.asset` 步骤配置

### 2. 清空配置（重新生成）

如需重新生成配置：

```
菜单栏 > Tools > 教程 > 清空教程配置
```

然后再次执行生成。

### 3. 启动教程

在代码中启动教程：

```csharp
// 加载教程流程配置
var guideFlow = Resources.Load<GuideFlow>("SO/Tutorial/GuideFlow_CatPlanet");

// 启动教程
this.GetSystem<IGuideSystem>().StartGuide(guideFlow);
```

### 4. 触发玩家动作

在相应的 UI 组件或游戏逻辑中发送玩家动作事件：

```csharp
// 示例：点击按钮时发送事件
this.SendEvent(new PlayerActionEvent(PlayerActionType.点击按钮));

// 示例：抽卡操作时发送事件
this.SendEvent(new PlayerActionEvent(PlayerActionType.抽卡操作));
```

## PlayerActionType 枚举

```csharp
public enum PlayerActionType
{
    无,
    
    // 通用动作
    点击任意处,
    点击按钮,
    悬停UI,
    点击继续,
    
    // 时间系统
    点击时间区域,
    
    // 食材系统
    抽卡操作,
    悬停食材,
    点击补充按钮,
    
    // 串制系统
    选择串签,
    右键旋转,
    左键确认串制,
    点击待售区,
    
    // 顾客系统
    点击顾客,
    悬停需求,
    点击出售,
    点击确认结算,
    
    // 目标与声望
    点击目标区域,
    完成交易,
    打开顾客志,
    点击经营日间,
    
    // 教程流程
    教程开始,
    教程完成,
}
```

## 扩展指南

### 添加新步骤

1. 在 `GuideConfigGenerator.cs` 的 `GenerateAllSteps()` 方法中添加新步骤
2. 重新执行 `Tools > 教程 > 生成猫猫星教程配置`

### 添加新的动作类型

1. 在 `PlayerActionEvent.cs` 的 `PlayerActionType` 枚举中添加新类型
2. 在相应的游戏逻辑中发送事件：
   ```csharp
   this.SendEvent(new PlayerActionEvent(PlayerActionType.你的新动作));
   ```

### 修改莫奇台词

直接修改 `GuideConfigGenerator.cs` 中对应步骤的 `guideText` 参数，然后重新生成配置。

## 数值预估

| 指标 | 预估值 |
|------|--------|
| 教程总步骤数 | 20 步 |
| 预计完成时间 | 8-12 分钟 |
| 第一天目标分数 | 500-800 分 |
| 初始食材卡数量 | 5 张 |
| 初始串签数量 | 2 根（1木串 + 1铁串） |
| 初始时间点 | 40 点 |

## 注意事项

1. **等待点击的步骤**：`waitForClick = true` 的步骤会在显示后等待玩家点击任意位置继续
2. **动作触发的步骤**：`waitForClick = false` 的步骤需要玩家执行特定动作才能继续
3. **教程跳过**：当前配置允许跳过（`canSkip = true`），可在 `GuideFlow` 中修改
4. **游戏暂停**：当前配置不会暂停游戏（`pauseGame = false`），可在 `GuideFlow` 中修改
